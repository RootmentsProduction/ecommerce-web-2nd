# Reels Video Assets Directory

Place your Instagram Reel video files (preferably in `.mp4` format) in this folder.

To match the default configuration, name your files:
- `reel-1.mp4`
- `reel-2.mp4`
- `reel-3.mp4`
- `reel-4.mp4`
- `reel-5.mp4`

If you use different filenames or have more/fewer reels, update the `reels` array in `src/components/home/InstagramSection.tsx`.
